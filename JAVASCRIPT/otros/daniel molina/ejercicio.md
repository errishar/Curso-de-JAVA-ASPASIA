EJERCICIO: ESTRUCTURA WEB CON TABLA E

IMÁGENES

Objetivo: Crear una página web utilizando etiquetas semánticas de HTML5 y un archivo CSS externo, practicando medidas en px, rem, %, vh, tablas, imágenes y efectos hover.

1. HEADER
• Será la cabecera principal de la página.
• Ocupará el 100% del ancho.
• Tendrá una altura de 150px.
• Incluirá un título principal relacionado con una galería de naturaleza.

2. NAV
• Estará situado debajo del header.
• Ocupará el 100% del ancho y tendrá una altura de 70px.
• Incluirá cuatro enlaces: Inicio, Galería, Lugares y Contacto.
• Al pasar el ratón sobre los enlaces deberá cambiar su color y el cursor deberá mostrarse en forma de mano.

3. CONTENEDOR PRINCIPAL
• Tendrá un ancho del 90%.
• Estará centrado horizontalmente utilizando margin: auto.
• Contendrá las zonas main y aside.

4. MAIN
• Ocupará aproximadamente el 70% del contenedor.
• Tendrá una altura mínima de 50vh.
• Incluirá un título, un pequeño texto introductorio y una tabla de 2 filas y 3 columnas.
• Cada celda de la tabla deberá contener una imagen.

5. ASIDE
• Ocupará aproximadamente el 30% del contenedor.
• Tendrá la misma altura visual que el main.
• Incluirá información secundaria, por ejemplo: lugares recomendados, tipos de paisajes o enlaces
relacionados.

6. TABLA
• Tendrá borde visible y ocupará el 100% del ancho disponible dentro del main.
• Las celdas deberán estar centradas.
• Se utilizará border-collapse: collapse.

7. IMÁGENES
• Se utilizarán imágenes guardadas dentro de una carpeta llamada img.
• Todas las imágenes deberán incluir el atributo alt.
• Las imágenes tendrán un ancho aproximado de 200px y mantendrán sus proporciones con height: auto.

8. FOOTER
• Será el pie de página.
• Ocupará el 100% del ancho.
• Tendrá una altura mínima de 120px.
• Incluirá un texto con el nombre del alumno y el año.

REQUISITOS CSS
• Utilizar un archivo CSS externo.
• Establecer en HTML un font-size de 20px.
• Utilizar box-sizing: border-box.
• Utilizar medidas en px, rem, % y vh.
• Añadir bordes a las principales zonas para distinguir claramente la estructura.
• Utilizar colores de fondo diferentes para header, nav, main, aside y footer.
• Main y aside deberán aparecer uno al lado del otro.
• Los enlaces del menú deberán tener efecto hover.
• Las imágenes deberán adaptarse correctamente dentro de las celdas de la tabla.
